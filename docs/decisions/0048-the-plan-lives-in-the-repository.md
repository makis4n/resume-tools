# 0048. The plan lives in the repository

Date: 2026-10-03 · Status: accepted, the owner's decision of 3 October 2026; amends 0001's line on
the editor plan

## Context

The editor plan began as a shared page and was converted to `docs/editor-plan.md` on 13 September
2026 (decision 0001). The page stayed the shareable copy and the file mirrored it, so agents were
told not to edit the file beyond a typo: a substantive change belonged on the page, in the owner's
hands. On 3 October 2026 the owner chose to keep one copy.

## Decision

- `docs/editor-plan.md` is the plan. The shared page is no longer kept up, and the README and the
  file itself no longer link to it.
- A substantive change to the plan is still the owner's. An agent edits the file when the owner
  asks for the change, and otherwise only fixes a typo.

## Consequences

- One copy, changed in a pull request and reviewed like any other change.
- The plan loses its shareable page. Sharing it means sharing the file.
- AGENTS.md's line on editing the plan says so.
